# GhostVoice
GhostVoice is a developer-first voiceover generation tool for Unreal Engine projects. It automates the creation of high-quality AI-narrated voice clips from in-game text using Amazon Polly, acting as a "ghost narrator" until final voiceovers are ready.

### 🔧 Key Features

-   🧠 Converts narration scripts into temporary AI-generated voice clips via Amazon Polly.
    
-   🎮 Seamlessly integrates with Unreal Engine 5 via `DataTable` or asset paths.
    
-   📁 Organizes audio assets for easy replacement with final voiceovers.
    
-   🔁 Ideal for rapid iteration in AAA and indie game development pipelines.
----------

### 📦 Tech Stack

-   Python (Polly TTS integration)
    
-   Unreal Engine 5
    
-   CSV / JSON narration input
----------

### 🚀 Use Cases

-   Narrative prototyping
    
-   Temporary voiceovers for pre-production
    
-   VO placeholder management in localization workflows
